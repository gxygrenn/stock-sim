## 二、七项分歧逐项裁决

### 分歧① 是否现在加仓（激进派 vs 交易员）——**否决激进派，采纳交易员"不加仓"**

| 维度 | 裁决 |
|------|------|
| **结论** | **不加仓。本阶段 0 股买入。** |
| **采纳谁** | 采纳交易员 / 研究主管；**否决激进派"现价加 100 股至 500 股"** |
| **激进派论点中我认可的部分** | "≥4 项门槛实质是加仓禁令"——成立。**但我采纳的解法是改门槛结构（分歧⑤），不是放弃门槛、在事件前投放现金。** |
| **否决的三条理由** | ① **事件前投放现金 = 在信息真空放大押注**：三季报是唯一硬证伪窗口（07/08），在结果未知前加仓，是用 30.9% 的现金去赌一个二元结果；② **无增量买盘 = 上涨缺触发者**：04 号报告确认六路资金全线流出，主力近 5 日 −7.27 亿、融资 11 连降，上涨需要一个"点火者"，而当前没有任何一路资金愿意充当；③ **激进派把行业 β 当个股 α**：9/10 政策催化的是**板块 42 股全涨**，而招行**不在 3,000 亿特别国债注资名单内**（03 号报告第 14 条），用行业利好论证招行个股加仓是范畴错误。 |
| **额外理由（资金效率论不成立）** | 激进派称 30,902 元闲置的年化机会成本 ≈ 1,044 元（账户 1.04%）。但**这笔"机会成本"是确定性的、而加仓的收益是不确定性的**——用一个确定的小额代价，换一个不确定的、且在三季报二元风险下的敞口放大，不是正期望的风险交换。**现金留到事件后，是"保留选择权"，不是"浪费"。** |
| **最终参数** | 现价 41.35 不加仓；加仓仅在"放量站上 41.78 **且** 三季报双轨验证通过"后启动（见第三节）。 |

### 分歧② 是否先减 200 股利用"零成本窗口"（保守派 vs 中性派）——**否决保守派，采纳中性派"不在成本线减仓"**

| 维度 | 裁决 |
|------|------|
| **结论** | **不在 41.35 主动减仓。本阶段卖出 0 股。** |
| **采纳谁** | 采纳中性派 / 交易员；**否决保守派"现价 41.35 减 200 股至 8.3%"** |
| **保守派论点中我认可的部分** | "尾部（0.69x）比提案口径深一层"——成立，**已并入分歧⑥的压力测试口径**。 |
| **否决的四条理由** | ① **减仓不锁定任何正收益**：现价 = 成本，卖出只把"0"从浮动变成确定，还要付双边手续费与点差——这是**支付成本去买一个尚未发生的风险**；② **40.09 距现价仅 −3.05%，在 2 倍 ATR 以内**（ATR14 0.672 / 日波动 1.62%），属正常噪音，**在噪音区主动减仓 = 把噪音当信号**；③ **基本面托底实在且无硬性利空**：PB 0.91（25% 分位）、股息 4.88%、不良 0.94%、拨备 385%~410%，无业绩变脸、无监管处罚、无大股东减持；④ **保守派把"零成本窗口"引申为"必须减仓"是偷换**——"零成本"只说明"此刻减仓不打折"，不说明"此刻应该减仓"。**真正的零成本窗口是 40.09 破位的第一时间（在破位信号处、而非在无信号处）。** |
| **保守派"节约的 2,004 元 > 风险预算"论证的漏洞** | 保守派称"减 200 股在 0.69x 情景下少亏 2,004 元，覆盖整个 2% 预算"。这个数字本身成立，但它**只计算了减仓的收益、未计算减仓的成本**：若三季报超预期（保守派自己承认的概率不低），减仓的 200 股会少赚 630 元（第一目标）+ 放弃 403 元/年股息。**我采纳中性派的替代路径：不动 400 股，而是把"减仓力度"前置到破位信号处——同样能把 0.69x 情景的损失压到账户 −1.86%（见第五节），却不付任何"未破位先减仓"的成本。** |
| **最终参数** | 本阶段卖出 0 股；减仓只在破位信号（40.09 / 38.03~38.20 / 34.28）触发后执行，且第一道防线力度加倍（分歧③）。 |

### 分歧③ 第一道减仓线 40.09 是否合理、减仓股数是 100 还是 200——**采纳 40.09 保留，股数采纳中性派 200/100/100**

| 维度 | 裁决 |
|------|------|
| **结论** | **保留 40.09 为第一道减仓线**（否决激进派"取消/下移至 38.03"）；**减仓股数改为 200/100/100**（否决交易员的 100/100/200，采纳中性派）。 |
| **采纳谁** | 对"线位"：采纳交易员（否决激进派）；对"股数"：采纳中性派（否决交易员）。 |
| **为何保留 40.09（否决激进派的下移）** | 激进派称 40.09 是"高频穿越带"、实证 8/25~8/28 连续四日收盘低于 40.09。**但这个实证恰恰证明的是"需要连 2 日收盘确认 + 股数前倾"，而不是"取消防线"。** 40.09 = MA20 + 布林中轨 + VWMA20 三线共振，是**当前技术结构唯一的多空分界**（01 号报告）；取消它、把第一道线下移到 38.03（−7.9%），等于放弃中期趋势的第一道验证，让 400 股在没有中间缓冲的情况下直面 38.03——这是把风险敞口放大，不是减小。 |
| **为何股数改为 200/100/100（核心裁决）** | 中性派的风险平价测算成立且可复算：三层每股亏损分别为 1.26 / 3.25 / 7.07 元，40.09（**概率最高**）只减 25% 股数、34.28（**概率最低**）却减 50% 股数并承担 75.8% 的亏损，是**典型的风险承担与发生概率倒挂**。改为 200/100/100 后： |
| **量化效果** | 最坏情形（三层精确成交）由 **−1,865 元 → −1,284 元**（少亏 581 元 / **−31.1%**），账户层面 **−1.87% → −1.28%**。**且只要不破 40.09，上涨情景收益与原方案完全相同（差异 0 元）。** |
| **附加保留（原方案规则①）** | 保留"反弹至 41.78~42.23 连续 2 日无法放量突破 → 主动减 100 股"（原方案 2.3 节①）。若该条已执行，剩余 300 股按 ①/②/③ **各 100 股**执行（采纳中性派 4.2 节的协调规则）。 |
| **最终参数** | 40.09（连 2 日收盘破位）→ **减 200 股**；38.03~38.20（收盘破位）→ **减 100 股**；34.28（收盘破位）→ **清 100 股**。 |

### 分歧④ 首道线用"连 2 日收盘"还是"单日收盘"——**采纳"连 2 日收盘"为主，叠加"跳空/放量例外"**

| 维度 | 裁决 |
|------|------|
| **结论** | **以"连续 2 日收盘破位"为主确认方式**（否决保守派的"单日收盘"），**但保留交易员原方案 4.3 节的两个例外**。 |
| **采纳谁** | 采纳交易员；**否决保守派"首道线改单日收盘"**。 |
| **否决单日收盘的理由** | 单日收盘确认会把 **−3.05%（不到 2 倍 ATR）的正常噪音当信号**。激进派提供的实证最有说服力：8/25~8/28 四个交易日中，**8/26 收盘 39.80 单日破位、8/27 收盘 39.58 重新站上**——若用单日规则，会在 8/26 被洗出、8/27 又要回补，**在破位区反复摩擦**（这正是保守派自己都承认要"同一价位只容错一次"的摩擦成本）。 |
| **采纳保守派"抗滑点"关切的正确方式** | 保守派"跳空会使执行价偏离线位"的关切是真实的，但**解法不是降低确认门槛（单日），而是提高减仓力度（200 股）+ 保留例外条款**： |
| **保留的两个例外（交易员原方案 4.3 节）** | ① **跳空低开直接跌破 40.09**：当日收盘确认破位即执行减仓，不机械等待"连 2 日"；但若跳空后收盘重新收回 40.09 上方，视为未破位；② **放量破位**（单日量 > 20 日均量 1.5 倍且收盘破 40.09）：视为有效破位，当日执行，不等第二日。 |
| **为何"200 股前置"同时解决了保守派的"两层确认期重叠"关切** | 保守派指出："两日各跌 5% 可使第一层与第二层的确认期重叠。" 采纳 200/100/100 后，**第一道防线一次性减掉持仓的一半**——即使第二、三层确认期重叠，账户的最大敞口也已被压缩一半，无需在快速下跌中追赶。**这是"前置减仓"对"确认期重叠"的对冲。** |
| **最终参数** | 首道线 40.09：连 2 日收盘破位（或跳空/放量例外当日）→ 减 200 股。 |

| **结论** | **改为"财报前价格纪律 / 财报后基本面纪律"双轨，并显性化"中性态"。门槛数值保持"≥4 项"不变。** |

| **采纳理由（为何这是纯改进）** | 原方案把"市场层条件"（放量站上 41.78、主力连续 5 日净流入）与"基本面层条件"（息差、关注类、零售）**混在同一个"同时满足 ≥4 项"的开关里**，导致两个执行死区：① **财报前**：即使市场层全部达标也无渐进响应，只能干等；② **财报后**：若只满足 2~3 项（**最可能的中性情形**），原方案**既不加仓（<4 项）也不减仓（未触发 3.7 节）——没有任何指令**。双轨 + 中性态正是填补这个指令真空。 |

| 维度 | 裁决 |
