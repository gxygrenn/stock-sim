### 6.2 PB 分位结论（明确）

**结论：PB 0.91 倍处于近三年约 25% 的历史低分位，判定为"低估（合理偏低）"。**

判断逻辑：
1. **PB 绝对值 0.91 倍 = 以 0.91 元买 1 元净资产**，对应 ROE 13.4%，隐含市场对"净资产可持续性"打了约 9% 的折扣，而招行不良率 0.94%、拨备 410%，净资产质量在业内最可信，**破净本身即提供了安全边际**；
2. **PB 历史分位 25.14% 明显低于 PE 历史分位 58.56%**，两者背离的原因是：净资产随利润稳步增长（每股净资产 43.43 → 45.40 元），而股价涨幅落后于净资产积累 → **PB 被动走低，属"基本面未恶化下的估值洼地"**，而非估值高企；
3. **PE 分位偏高（58.56%）应正确解读**：PE = PB ÷ ROE，招行 ROE 是同业近 1.5 倍，PE 分位高是"高 ROE 的合理结果"，同时反映"零增长"预期已部分计价，**不能据此判定高估**；
4. **交叉验证**：41.35 ÷ 45.40（每股净资产）= 0.911，与接口返回 PB 0.91 完全一致，数据自洽可信。

## 七、亮点与风险

### 7.1 两大基本面亮点
1. **资产质量行业最优 + 拨备安全垫极厚**：不良率 0.94%（vs 行业约 1.5%）、拨备覆盖率 410.03%（监管红线 2.7 倍）、不良/逾期90天以上 1.23 → 风险抵御能力与未来利润弹性（拨备反哺）双优。
2. **高 ROE + 高股息 + PB 历史低分位**：加权 ROE 13.44% 领跑同业，股息率约 4.88%，PB 0.91 倍处历史 25% 分位，派现募资比 605.66 倍行业第 1 —— 典型的"高质量底仓资产"组合。

### 7.2 两大主要风险点
1. **零增长 + 净息差持续下行**：3 年营收 CAGR −0.05%、归母净利 CAGR +0.30%；净息差披露值 2026H1 接口未返回，2025Q1 NIM 已同比 −11bp 至 1.91%，2026H1 净利息收入 +5.6% 全靠规模 +8.91% 支撑，"以量补价"不可长期持续。
2. **前瞻资产质量指标边际转差 + 零售风险暴露**：关注类贷款率 1.29%→1.43%（2025Q3）、余额破千亿；信用卡不良 1.75%/关注 4.60%、消费信贷不良 1.64%/关注 3.35%、房地产业公司贷款不良 4.24%，零售与地产仍是压力源。

## 九、对持仓（400 股 / 成本 41.35 元）的基本面结论

1. **基本面不支持减仓**：ROE 13.44%、不良 0.94%、拨备 410%、股息率 4.88%、PB 0.91（历史 25% 分位），招行仍是 A 股银行板块基本面最强的标的之一，当前成本 41.35 元对应 PB 0.911，处于"破净买入"区间。
2. **但也不支持追加至重仓之上**：零增长（营收/净利 3 年 CAGR ≈ 0）+ 净息差下行 + 关注类贷款率上行，决定其上行弹性有限，**更多是"赚 ROE 与股息的钱"，而非"赚成长的钱"**。仓位已占总资产 16.6%，进一步加仓将放大单一板块（大金融）集中度风险。
3. **建议姿态（基本面视角）**：**持有，不加不减**；若出现以下信号可考虑调整——
   - **加仓信号**：2026 年三季报确认不良率维持 ≤0.95%、关注类贷款率回落、净息差降幅收窄至 5bp 内、中收延续正增长；
   - **减仓信号**：拨备覆盖率跌破 350%、关注类贷款率升破 1.6%、或 PB 修复至 1.1 倍以上（历史 60%+ 分位）而 ROE 继续下滑。
4. **对本次模拟交易决策的输入**：基本面为**中性偏多但弹性有限**，方向上支持"持有/逢回调小幅加仓"，不支持"追高加仓"；最终决策需结合市场分析师的技术面与团队的情绪/新闻判断综合定价。
