# 模拟炒股多版本对照实验

> 股票模拟交易机器人：10 万元虚拟本金、15 只自选股票池，云端 7×24 运行，消息驱动 + LLM 专家团评审，全自动闭环。

## 项目简介

本仓库包含一个 **股票模拟交易系统**，含 **A 股稳健版 / A 股激进版 / 美股版** 三个参数不同的对照实验，以及一个交易工作台。均运行在 WorkBuddy 云端，实现「采集 → 打分 → LLM 评审（交叉验证）→ 交易时段自动成交」的完整闭环。

## 快速开始

### 本地运行（纯 Python 标准库，无需安装依赖）

```bash
cd stock-sim && python server.py        # A股稳健版，端口 8000
cd aggressive-app && python server.py   # A股激进版，端口 8000
cd us-stock-app && python server.py     # 美股版，端口 8000
cd trade-desk && python server.py       # 交易工作台，端口 8123
```

访问 `http://localhost:8000/` 或 `http://localhost:8123/` 查看面板。

## 三版本参数对照

| 参数 | A股稳健版 | A股激进版 | 美股版 |
|---|---|---|---|
| 股票池 | 15 只 A 股 | 15 只 A 股 | 15 只美股 |
| 指数 | 上证 sh000001 | 上证 sh000001 | 标普500 usINX |
| 交易时段 | 9:30-15:00 | 9:30-15:00 | 北京时间 21:30-次日4:00（夏令时）|
| autoTrade（门控）| False | False | False |
| minScore | 4 | 2 | 2 |
| buyPct / maxPosPct | 20% / 30% | 35% / 45% | 20% / 30% |
| minAgree / maxHold | 2 / 8 | 1 / 12 | 2 / 8 |
| 信号源 | 技术+龙虎榜+公告+估值 | 技术+龙虎榜+公告+估值 | 技术+新闻（龙虎榜/公告/估值关闭）|
| 整手 | 100 股 | 100 股 | 1 股 |
