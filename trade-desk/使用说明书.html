一、它能做什么

📊 行情监控A股、港股、美股、国内期货四类标的的实时看板，支持涨跌提醒
💰 持仓交易记录买卖流水，自动算持仓成本、市值与浮动盈亏
📝 每日复盘自动生成复盘底稿，记录心得标签，系统从历史中提炼你的经验
🧪 策略回测双均线、均线突破两种经典策略，历史数据验证，图形化展示买卖点

数据来源为腾讯财经与新浪财经的免费公开接口，由服务端代理抓取，打开网页即可使用，无需注册、无需 API Key。

二、三分钟上手

  1. 打开 https://trade-desk-terminal.app.workbuddy.host/，看到三个页签：行情监控 / 持仓交易 / 策略回测。
  2. 在「行情监控」页输入一个代码（例如 sh600519）点「添加自选」，或直接点快捷按钮。
  3. 行情每 20 秒自动刷新；点某行右侧的「设提醒」可以设置价格/涨跌幅预警。
  4. 切到「持仓交易」，把实际买入记一笔（方向、代码、价格、数量），持仓盈亏自动生成。
  5. 切到「策略回测」，输入代码点「开始回测」，看 K 线买卖点和收益统计。

四、功能详解

📊 行情监控

  • 自选列表：展示名称、现价、涨跌幅、今开/最高/最低、行情时间。红色 = 上涨、绿色 = 下跌（A股习惯配色）。
  • 自动刷新：页面停留时每 20 秒刷新一次行情，每 60 秒自动检查一次提醒；也可随时点「刷新行情」。
  • 设提醒：点自选行右侧「设提醒」，代码会自动填入下方表单。四种规则：
    • 价格 ≥ / ≤ —— 跌到位、涨到位提醒（如设置 below 1200）
    • 涨幅 ≥ % / 跌幅 ≤ % —— 盯当日涨跌幅（如 pct_up 3 表示涨超3%提醒）
  • 触发效果：满足条件后该行整行高亮、标记「已触发」并记录触发时间与当时价格；规则会保留，不需要时手动删除。

💰 持仓交易

  • 录入：选择买入/卖出 → 填代码、成交价、数量 → 「记一笔」。留空价格或数量会提示错误。
  • 持仓计算：多次买入自动摊薄成本（加权平均）；卖出按成本扣减。当前市值与浮动盈亏按实时行情计算。
  • 顶部卡片：总市值、总浮动盈亏一目了然。
  • 流水管理：每笔流水可单独删除，删除后持仓重新计算。
💡 说明：持仓模块是记账工具，不会连接券商、不会真实下单。行情停牌或源故障时会标注「行情数据不可用」，此时按成本价暂估市值。

📝 每日复盘

  • 生成底稿：选日期点「生成底稿」，自动汇总当日自选涨跌、当日交易流水与持仓盈亏快照，省去手工抄数。
  • 写复盘：选市场情绪（乐观/中性/谨慎/悲观）、填当日浮动盈亏、点选行为标签（追高、止损、拿住、纪律好…可自定义）、写心得，保存即可。同一日期重复保存会覆盖当天旧复盘。
  • 经验洞察（学习引擎）：系统统计每个行为标签出现时段的盈亏——
    • 只有重复出现 ≥2 次的标签才被视为"经验模式"，单次偶然不计入；
    • 自动生成教训，例如：「追高」出现过的 N 个交易日平均亏损 X 元——这是你最需要警惕的行为模式；
    • 做得好的行为也会被点名表扬，帮你把它固化成纪律。
  • 复盘历史：按日期倒序展示，点击可展开心得与底稿快照。
💡 用法建议：每天收盘后花 2 分钟：生成底稿 → 点标签 → 写一两句心得。坚持 5 篇以上，洞察的参考价值会明显提升。

🧪 策略回测

  • 双均线金叉/死叉：短期均线上穿长期均线买入（金叉），下穿卖出（死叉）。默认 MA5 / MA20，可自行调整。
  • 均线突破：收盘价上穿 N 日均线买入，下穿卖出。
  • 规则：信号当日收盘价成交、全仓进出，计入双边手续费（默认 0.08%/次），初始资金默认 10 万。
  • 图表：上方为 K 线 + 均线 + ▲买▼卖标记；下方为策略权益曲线。
  • 统计指标：总收益率、年化收益、最大回撤、交易次数、胜率，以及与「买入持有」的对比。
⚠️ 重要提醒：回测采用历史数据与理想化假设（收盘成交、无滑点、无停牌跳空处理），过去表现不代表未来收益。回测结果仅用于理解策略特性，不构成任何投资建议。

五、常见问题 FAQ

问题解答
行情多久更新一次？页面打开时每 20 秒自动刷新。免费接口为延时/快照行情，非 tick 级实时，节假日与非交易时段显示最近一次收盘数据。
某行显示「行情数据不可用」？该数据源暂时抓取失败或代码不存在。其他市场不受影响；稍后点「刷新行情」重试，长期失败请检查代码格式。
期货为什么用新浪而股票用腾讯？腾讯接口不提供国内期货行情，新浪提供；系统已自动按代码前缀路由，无需关心。
数据保存在哪里？会不会丢？保存在服务端 JSON 文件中（自选 / 提醒 / 流水），刷新页面、关闭浏览器都不会丢失。
回测可以用于期货吗？可以，期货日 K 走新浪接口，如 nf_RB0。但注意回测按「股数」计算，未乘合约乘数，期货结果仅供趋势参考。
能提醒我手机吗？目前提醒在页面内展示（需保持页面打开）。如需推送通知可后续扩展。
复盘标签可以自己加吗？可以，在「+加标签」输入自定义标签；标签越贴近你真实的行为模式，经验洞察越有价值。
经验洞察是怎么算的？把每篇复盘的「行为标签」与当天的浮动盈亏关联：同一标签出现 ≥2 次即视为模式，统计其平均盈亏与胜率，按平均盈亏排序给出教训。
支持外汇/加密货币吗？当前版本聚焦 A股/港股/美股/国内期货，其他市场可按需扩展。

七、本地部署（可选）

想在自己电脑跑一份？项目只有两个文件：

  1. 安装任意 Python 3.10+（无需 pip 装任何包）；
  2. 把 server.py 与 index.html 放同一目录；
  3. 运行 python server.py，浏览器打开 http://127.0.0.1:8123。
  4. 换端口：PORT=9000 python server.py（Windows PowerShell：$env:PORT=9000; python server.py）。
